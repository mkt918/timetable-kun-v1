# 時間割くん v2

高校向けの時間割作成ツールです。ブラウザで動くWebアプリで、v1を作り直したものです。

## 使い方（5ステップ）

1. **準備**：基本設定 → クラス → 教科・科目 → 先生 →（特別教室・会議）
   - 名簿などは Excel で範囲をコピーし、「表から貼り付け」で一括登録できます
2. **授業**：「どの科目を・どのクラスに・どの先生が・週何コマ」を1行で登録します
   - クラスを2つ以上選ぶと **合同**、先生を2人以上選ぶと **TT** になります
   - 「置き方」で2コマ・3コマ連続を指定できます
   - 選択授業など、同じ時間に並べて行う授業は **選択群** にまとめます
3. **時間割を作る**：右の「未配置」から授業をクリック → 緑のマスをクリックで配置
   - ドラッグ＆ドロップでもOK。置いた授業をクリック → 別のマスで移動、別の授業で入れ替え、Delete で外す
   - 「自動配置…」で空いている所を一括で埋められます（固定した授業は動きません）
4. **チェック**：重なり・勤務不可・会議との重複・未配置を一覧で確認
5. **印刷**：クラス別・先生別・教室別・一覧表。PDF保存も可

`Ctrl+Z` で元に戻す、`Ctrl+Y` でやり直し（100回まで）。

## データの保存

- 入力内容はこのブラウザに自動保存されます（サーバーには送られません）
- 別のパソコンで使うときやバックアップは「データ」画面の **ファイルに保存（.json）** を使ってください
- v1 のデータとは互換性がありません

## v1 からの主な変更点

| v1 の不満 | v2 での対応 |
|---|---|
| 担当授業・クラス別設定・合同/TT設定が別々の画面 | 「授業」1行に統合（クラス・先生の人数で合同/TTが決まる） |
| 配置操作がモーダル中心で手数が多い | 授業カードを選ぶと置ける枠が緑に光り、1クリックで配置 |
| 置けない理由が分からない | グレーの枠にマウスを乗せると理由を表示 |
| 画面が散らばっている | 左メニューを「準備 → 作成 → 仕上げ」の順に整理、「はじめに」に進み具合を表示 |
| JSONバックアップに一部データが入らない | すべてのデータを1ファイルに保存 |

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # dist/ に出力
```

- React + TypeScript + Vite。ロジックは `src/core/`（画面に依存しない純粋関数とテスト）、画面は `src/ui/`
- `main` ブランチへの push で GitHub Pages に自動公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）
- v1 のコードは `legacy/` に残しています
